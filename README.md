# ♟️ Chess Board

A simple Chess Board created using HTML5 and CSS3. This project focuses on creating a chessboard layout using HTML elements and CSS styling.

## 🚀 Features

- 8×8 Chess Board
- Classic black and white board design
- Built with pure HTML and CSS
- Simple and clean layout
- Beginner-friendly project

## 🛠️ Technologies Used

- HTML5
- CSS3
